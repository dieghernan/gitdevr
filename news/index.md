# Changelog

## gitdevr 0.0.0.9000

- Quarto callout icons retain their shapes and now follow the site theme
  and brand colors through CSS masks.
- Code blocks now use the GitHub palette in light mode and One Dark in
  dark mode, with small adjustments to comments and One Dark names for
  accessible contrast.
- Navigation hover and focus states have improved contrast, and linked
  code tokens retain their underline.
- Mobile code blocks scroll within their containers.
- Page transitions and callout icon animations respect reduced motion
  preferences.
- The package is in active development.
- [`test()`](https://dieghernan.github.io/gitdevr/reference/test.md) now
  returns `NULL` invisibly, as documented.
